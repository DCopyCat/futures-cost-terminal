## Windows 使用

**v0.5.1 启动修复：** 双击 `启动工作台.bat` 时仅由 Streamlit 自动打开一次默认浏览器；已移除额外的 PowerShell 打开网页命令。若需要手动访问，仍可在运行中的本机打开 `http://127.0.0.1:8501`。更新 GitHub 代码不会自动覆盖旧版解压目录，请先停止旧命令行窗口并替换本地启动脚本或拉取本分支合并后的稳定版本。


1. 先关闭旧版的黑色命令行窗口，避免 8501 端口冲突。解压 v0.5 ZIP 到单独文件夹（建议只用英文路径）。
2. 安装 Python **3.11 / 3.12**；双击 `启动工作台.bat`。首次安装依赖需要联网。此后重新启动不再每次执行 pip install。
3. 浏览器进入 `http://127.0.0.1:8501`。点击 **「免费更新并生成真实日报（CNEquity）」**。第一次会创建 `cn_equity_lake/cnequity.futures.toml`、启用期货模块、采集最近约 8 个自然日的 `futures_bars`，之后读取已发布的行情生成报告。大商所新浪路由首次可能逐个枚举数百合约，请保留启动窗口、查看页面采集步骤。也可先取消「同时采集大商所」勾选，先验证其余市场（此时报告不完整）。**无需下载整个 A 股库**。
4. 主页面按各品种报告日**持仓量最大**选择具体期货合约，输出前一完整交易日结算价、公司默认开仓费、平昨参考费、平今核验费、日内和隔夜一开一平成本（含双边保障基金），以及保证金与缺失项。点击 ZIP/CSV/HTML 下载。
5. 如果没有数据显示，展开 **「CNEquity 免费数据源检查 / 上次失败日志」**，下载 `cne_last_run.json`。也可查看本机 `logs/cne_last_run.json`、`logs/last_error.txt`。错误不是价格 0，也不是模拟数据。
6. 「查看演示效果」只用虚构数据测试 UI；绝不能对客。

## 免费行情接入路线

- CNEquity 官方文档：<https://github.com/rootSunc/CNEquity> / <https://rootsunc.github.io/CNEquity/recipes/derivatives/>。
- 首次配置使用 `cne config create`，期货启用 `exchanges=["SHF","CZC","GFE","CFE","DCE"]`。**INE 经 SHF 路由覆盖**。
- 行情按交易所源端日文件取得；**DCE 默认 `dce_route = "sina"`**，可能缺零成交合约，不能宣称大商所完整覆盖。
- 使用 `cne backfill futures_bars` 更新短窗口，然后 `cnequity.query.load("futures_bars", config=...)` 查询本机 Parquet；不依赖付费 Token 获取行情。
- 若上游返回 403/412/429，工具遵守源端限制、记录日志，不执行反爬验证绕过。

## 保证金与手续费的事实边界

- **CNEquity `futures_bars` 含结算价/持仓量，不包含已验证的逐日交易所保证金率或交易手续费费率。** 免费行情解决的是主要行情无法拉取，而不是公司的全部业务参数。
- 其他五市场的交易所结算参数仍尝试 AKShare `futures_settle`；大商所保证金采用同交易日人工核验 CSV 或可选的授权 Tushare。失败时显示待核，绝不借用旧日保证金。
- 公司手续费来自先锋期货 **2026-11-02** PDF 的 88 条开户默认交易手续费，保障基金成交金额**亿分之九**按每次成交另计。**PDF 没有独立列出平昨、平今收费**：开仓按默认单边费率估算；平昨只按同一默认单边费率试算，标注“未独立确认”；平今没有公司确认覆盖标准时填「待核」，日内一开一平合计也留空。
- 每日主力表有一手开仓/平昨/平今手续费、各自含单边基金金额、隔夜/日内两笔开平交易的合计费用（含双边基金），两笔交易默认假设均以报告日结算价成交。
- 界面提供**价格和手数速算**：选合约，填写开/平仓实际成交价与手数，模拟费用。不保存任何客户身份信息；客户账户专属费率、平今手续费及公司加收保证金必须核验公司系统。
- 交易所结算价仅用于参考估算，并非成交价格，也不代表客户真实成交费用。
- **选择主力合约依据同一交易日持仓量，不使用 CNEquity 的 `futures_continuous` 复权价格。**
- 最新性：若只有历史日数据，工作台不构造新日期。报告有源端返回状态与市场日期，客户使用前核实。

## 数据与配置位置

- `cn_equity_lake/`：免费本地期货湖及配置；备份时可保存它。
- `data/company_fees.csv`：2026-11-02 先锋默认费率；`data/company_overrides.csv`：手工费率与保证金覆盖参数（新增 `close_yesterday_fee_type`、`close_yesterday_fee_value` 两列）。填入特定费率时自行确认该配置适用账户，勿填客户个人信息。
- `reports/`：真实结算日报输出（含审计 JSON），`logs/`：抓取失败诊断。
- 从 v0.3 / v0.4 升级且已录入手工参数，**只复制旧版 `data/company_overrides.csv` 和 `data/exchange_overrides.csv`**；不要覆盖 2026-11-02 最新公司费率。

## v0.5 手续费计算与示例

- 计费类型：`RATE` 乘以 `成交价 × 合约乘数`，`FIXED` 则按元/手收费；先按单边计算后再求和。默认单张日报假设开、平两边成交价均等于当日结算价，速算器可输入不同成交价。
- `开仓`：公司默认费率（参考值）。`平昨`：单独覆盖费率优先；无覆盖时沿用开仓默认费率作为**待核估算**。`平今`：只有填入公司覆盖项且计费类型/数值完整才计算，包含**明确填 0** 的免收情形。
- `隔夜一开一平`：开仓 + 平昨。`日内一开一平`：开仓 + 平今。`含保障基金`：额外加开、平两笔成交各自的保障基金。缺少平仓规则时不显示合计。
- 假设螺纹钢结算价为 3040 元/吨、乘数为 10 吨、公司默认比例为 0.0005，则开仓参考费为 15.20 元/手，平昨仅参考 15.20 元/手，隔夜开平合计不含基金 30.40 元/手。**这是假设数据的计算示例，不是当天行情。**
- 所有数字仅用于业务沟通前的内部估算：期货公司最终实际收费以客户账户适用费率、交易所当日公告、成交价格、开平仓属性和交易结算单为准。
